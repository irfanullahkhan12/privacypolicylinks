# Privacy policies and terms

Policy pages for Bathan Dev's apps and websites, served with GitHub Pages so
app stores and in-app settings have a stable link.

| App | Privacy policy | Terms |
|-----|----------------|-------|
| Temp Mail / TempMails.online | [tempmails/privacy-policy.html](https://irfanullahkhan12.github.io/privacypolicylinks/tempmails/privacy-policy.html) | [tempmails/terms.html](https://irfanullahkhan12.github.io/privacypolicylinks/tempmails/terms.html) |

## Publishing

Settings → Pages → Build and deployment → Source: **Deploy from a branch**,
branch **main**, folder **/ (root)**. Pages are live a minute after each push.

## Adding an app

Make a folder for it with `privacy-policy.html` and `terms.html`, copy the
structure of `tempmails/`, and add it to the list in `index.html` and here.

## Temp Mail pages

These are the same text as https://www.tempmails.online/privacy and
https://www.tempmails.online/terms, and point to them as the canonical copy.
They are generated from the website, so change the text there first and then
regenerate; editing only one copy lets them drift apart.
